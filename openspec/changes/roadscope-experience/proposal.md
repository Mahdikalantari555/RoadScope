# roadscope-experience

## Why

The current dense, English-only interface needs a coherent map-first experience while preserving working analytical flows.

## What Changes

Build a bilingual Persian/English interface combining the strongest navigation, map, overview and analysis patterns from FrontExamples without importing their incompatible APIs.

## Capabilities

### New Capabilities

- `bilingual-map-workspaces`: Build a bilingual Persian/English interface combining the strongest navigation, map, overview and analysis patterns from FrontExamples without importing their incompatible APIs.

### Modified Capabilities

None. These are proposed new specifications; they do not assert that the capability is already implemented.

## Impact

frontend components, localization resources, accessible controls, MapLibre layout and end-to-end tests.

## Dependencies and scope

roadscope-foundation; scientific controls depend on their respective completed API changes. See `IMPLEMENTATION_PLAN_FA.md` for sequencing. Out of scope: representing synthetic or unvalidated results as operational safety conclusions.
